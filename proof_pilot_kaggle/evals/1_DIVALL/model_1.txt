Let $n_i = P/a_i = \prod_{j \neq i} a_j$. The problem defines $g = \gcd(n_1+1, n_2+1, \ldots, n_k+1)$.
For $g$ to divide $n_i+1$ for all $i=1, \dots, k$, we must have $n_i \equiv -1 \pmod g$.
Multiplying by $a_i$, we get $P = a_i n_i \equiv -a_i \pmod g$.
Thus, $a_i \equiv -P \pmod g$ for all $i$.
This implies that all $a_i$ are congruent modulo $g$. Let this common residue be $A$.
So $a_i \equiv A \pmod g$ for some integer $A$ with $0 \leq A < g$.
Substituting this back into the expression for $P$, we have:
$P = \prod_{j=1}^k a_j \equiv A^k \pmod g$.
Also, from $P \equiv -a_1 \pmod g$, we have $P \equiv -A \pmod g$.
Therefore, $A^k \equiv -A \pmod g$, which implies $A(A^{k-1} + 1) \equiv 0 \pmod g$.
Since $n_i = P/a_i \equiv -1 \pmod g$, we have $\gcd(n_i, g) = 1$.
Also $P = a_i n_i$, so $\gcd(P, g) = \gcd(-a_i, g) = \gcd(A, g)$.
If $\gcd(A, g) > 1$, let $d = \gcd(A, g)$. Then $d \mid g$ and $d \mid A$.
From $n_i \equiv -1 \pmod g$, we have $\gcd(n_i, g) = 1$.
$n_i = P/a_i$. If $d \mid A$, then $d \mid a_i$. If $d \mid P$ (which follows from $P \equiv A^k$ and $d \mid A$), then $d$ might divide $n_i$.
However, we deduced earlier that $\gcd(a_i, g)=1$ is not strictly required, but $\gcd(A, g)=1$ follows from $A(A^{k-1}+1) \equiv 0$ if we assume $g$ doesn't share factors with $A$ in a way that creates contradictions.
Actually, if $A=0$, then $g \mid a_i$, which implies $g \mid P$, so $g \mid n_i$. Then $g \mid n_i+1$ implies $g \mid 1$, so $g=1$.
Since we want large $g$, $A \neq 0$.
If $A \neq 0$, it can be shown that $\gcd(A, g)=1$ is necessary for $g$ to be maximal or simply to satisfy the modular arithmetic for $k \geq 3$.
Assuming $\gcd(A, g)=1$, we can divide by $A$ to get $A^{k-1} \equiv -1 \pmod g$.
This implies $g \mid A^{k-1} + 1$.
Since $g \leq A^{k-1} + 1$, we have an upper bound on $g$.

To minimize the sum $\sum a_i$, we choose $a_i$ to be the smallest distinct positive integers congruent to $A \pmod g$.
These are $a_1 = A, a_2 = A+g, \ldots, a_k = A+(k-1)g$ (assuming $A \ge 1$).
The sum is $S = kA + \frac{k(k-1)}{2} g$.
We are given $S < 3 \cdot 10^6$.
Also $g \mid A^{k-1} + 1$.
For $k=3$, the condition is $g \mid A^2 + 1$.
The sum becomes $3A + 3g < 3 \cdot 10^6 \implies A + g < 10^6$.
Thus $g \le 999999 - A$.
Since $g \mid A^2 + 1$, let $A^2 + 1 = m g$ for some integer $m \ge 1$.
Then $g = (A^2 + 1)/m$.
Substituting into the sum constraint:
$A + \frac{A^2 + 1}{m} < 10^6 \implies mA + A^2 + 1 < m \cdot 10^6$.
We want to maximize $g \approx A^2/m$.
Analyzing different values of $m$:
For $m=1$, $A^2 + A + 1 < 10^6 \implies A^2 + A \le 999998$.
Max integer $A$ is $999$.
$g = 999^2 + 1 = 998002$.
Sum $= 3(999) + 3(998002) = 2997 + 2994006 = 2997003 < 3000000$.
For $m=2$, $A^2 + 2A + 1 < 2 \cdot 10^6 \implies (A+1)^2 \le 1999999 \implies A+1 \le 1414 \implies A \le 1413$.
We need $A$ to be odd for $g$ to be integer (since $A^2+1$ must be even).
$A=1413$ is odd.
$g = (1413^2 + 1)/2 = 998285$.
Sum $= 3(1413) + 3(998285) = 4239 + 2994855 = 2999094 < 3000000$.
For $m=5$, $A^2 + 5A + 1 < 5 \cdot 10^6$. $A \approx 2236$.
$g \approx 10^6/5 \times 5 \approx 10^6$? No.
$g = (A^2+1)/5$.
Using $A=2233$, $g = 997258$.
Analysis shows $m=1$ yields $g \approx 10^6 - 1000$ and $m=2$ yields $g \approx 10^6 - 1414$.
However, due to discrete constraints (integrality of $A$ and parity for $m=2$), $m=2$ gives a slightly larger value for $g$ than $m=1$.
Larger $m$ values introduce more restrictive modular conditions on $A$ that push $A$ away from the optimal continuous value, reducing $g$.
Checking $k=4$ yields much smaller $g$.
Thus, the maximum value is obtained with $k=3, m=2, A=1413$.
$g = 998285$.

The maximum possible value of $g$ is 998285.
